# Рецепт: Оладьи на кефире
[оригинал](da.ru/recepty/vypechka-deserty/oladi-na-kefire-29574)

### Ингредиенты
| Название        	 | Количество        |
| -------------   	 |:----------------: |
| Кефир  	         | ½ л               |
| Сахар 	         | 3 столовые ложки  |
| Соль	             | 1 чайная ложка    |
| Пшеничная мука	 |   2 стакана       |
| Сода            	 | 1 чайная ложка    |
| Растительное масло | по вкусу          |
| Пшеничная мука     | 180 г   	         |
| Сливочное масло    | по вкусу          |
| Сметана            | по вкусу          |
| Варенье            | по вкусу          |

## Описание
Классическая будничная еда, которая чаще всего возникает в доме,
 если надо спасать кефир. Если правильно обращаться с содой,
 которая отвечает за пышность оладий, то толщина у них будет не хуже,
 чем у дрожжевых. Можно есть с вареньем, медом или сметаной, а можно
 и просто так, слегка присыпав сахарной пудрой.
 
## Рецепт приготовления
1 Кефир смешать с сахаром, солью и содой.

2 Постепенно вмешать муку так, чтобы получилось тесто консистенции густой сметаны.

3 Разогреть сковороду. Если она не антипригарная, 
добавить масло: сливочное, растительное или их смесь.

4 Выложить тесто столовой ложкой на раскаленную сковороду, жарить 
около полутора минут, на поверхности теста должны появиться пузырьки,
 а внизу тесто должно зазолотиться.
 
 5 Перевернуть оладьи и жарить их еще около минуты, до такого же 
 золотистого цвета. Так же поступить со всем тестом. Подавать оладьи 
 со сметаной и любимым вареньем.
